# World Labs — Unity Middleware
**Unity 6000.3 | Built-in Render Pipeline**

A Unity Editor integration for the [World Labs](https://www.worldlabs.ai) API.
Generate and import Gaussian Splat 3D environments directly into your Unity
project from a text prompt, image, or video — no manual export required.

---

## Setup

### 1 — Install the Gaussian Splatting Package

1. Open `Window > Package Manager`
2. Click `+` → **Add package from git URL**
3. Paste:
```
https://github.com/aras-p/UnityGaussianSplatting.git?path=package
```

### 2 — Configure your API Key

1. Open `Tools > World Labs > World Labs Editor`
2. Go to the **Settings** tab
3. Paste your World Labs API key
4. Click **Save** then **Test Connection**

The key is stored in `EditorPrefs` (machine-local). It is **never** written to
any asset file or committed to source control.

## Editor Window

Open via **Tools > World Labs > World Labs Editor**.

### Settings
Configure API key, default generation model, default splat resolution, and
the default import folder.

### World Browser
Lists all your generated worlds with status, creation date, and model.
Click **Import** on any `SUCCEEDED` world to start the download pipeline.

### Generate
Enter a text prompt to trigger a new world generation.
Choose model (`marble-1.1`, `marble-1.1-plus`, …), seed, and display name.
The window polls the operation automatically every few seconds.

### Import
Pick splat resolution (Full / 500k / 100k gaussians), toggle collider mesh
and panorama download, then click **Import World**.
All files are saved to `Assets/GaussianAssets/<WorldName>/`.

## Scene Hierarchy

Every imported world produces this structure:

```
WorldName              <- position, scale; rotation = identity
├── GaussianSplat      <- GaussianSplatRenderer; localRotation (0, 0, -180)
└── Collider           <- MeshCollider + PhysicsMaterial; rotation = identity
```

**Why the -180 Z rotation?**
World Labs SPZ data uses a coordinate convention where Y is flipped and X is
mirrored relative to what the Aras package expects in Unity space. The -180° Z
rotation corrects both axes simultaneously and is a systematic platform
difference — not a per-world quirk.

The collider GLB is converted automatically by Unity's built-in glTF importer
(vertex-level right-to-left-handed conversion), so it arrives already in Unity
space and needs no additional rotation.

## Manual GaussianSplatAsset Creation

If the automatic `GaussianSplatAssetCreator` lookup via reflection fails,
a dialog appears explaining the manual steps:

1. Open `Tools > Gaussian Splats > Create GaussianSplatAsset`
2. Set **Input File** → the `.spz` inside `Assets/GaussianAssets/<WorldName>/`
3. Set **Output Folder** → the same directory
4. Click **Create Asset**
5. The `GaussianSplat` child already has a `GaussianSplatRenderer` — drag the
   created `.asset` onto its **m_Asset** field in the Inspector

## Architecture Notes

**Editor-only pipeline**
All middleware scripts live under `Assets/Editor/` or are guarded with
`#if UNITY_EDITOR`. Nothing is included in player builds.

**Reflection-based GS integration**
The dependency on `org.nesnausk.gaussian-splatting` is resolved at runtime via
reflection to avoid a hard compile-time reference. The package can be updated
independently without recompiling the middleware. If the type lookup fails, the
console prints all available `Gaussian*` types so the correct name can be
identified and added to the candidate list in `GaussianSceneBuilder`.

**JSON parsing strategy**
The World Labs API uses snake_case keys and some fields have names beginning
with digits (`"500k"`, `"100k"`) which `JsonUtility` cannot deserialize.
`WorldLabsJsonHelper` uses `JsonUtility` for the bulk of each response and
falls back to `System.Text.RegularExpressions.Regex` for problematic fields and
for the `status` field (which may arrive as a string or a numeric proto enum).

**API key security**
The key is stored in `EditorPrefs` under `WorldLabs_ApiKey`. It is never
written into any `.asset`, `.json`, or `.cs` file and is excluded from version
control by design.
